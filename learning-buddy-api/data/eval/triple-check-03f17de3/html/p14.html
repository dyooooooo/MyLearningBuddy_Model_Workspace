1.1 集合初步

我们常用文氏图(Venn diagram)来直观表示集合以及集合之间的关系. 图 1-1-3 是 A⊆B 的文氏图.

上述四组集合中的每组都有 C⊆D. 但是，第(1)(2)组与第(3)(4)组是有区别的. 在第(1)(2)组中，集合 D 中有些元素不属于集合 C，即 D 不是 C 的子集；而在第(3)(4)组中，集合 D 中的每个元素都属于集合 C，即 D⊆C.

对于集合之间的包含关系，我们有下列结论：

(1) A⊆A；

(2) 若 A⊆B 且 B⊆A，则；

(3) 传递性：若 A⊆B 且 B⊆C，则 A⊆C.

由此，对第(3)(4)组集合，成立；而对第(1)(2)组集合，不成立. 为此，我们引入真子集的概念.

定义 对于两个集合 A 与 B，如果 A⊆B，且 B 中至少有一个元素不属于 A(即 B 不是 A 的子集)，那么称集合 A 是集合 B 的真子集(proper subset)，记作 A⊂B(或 B⊃A)，读作“A 真包含于 B”(或“B 真包含 A”).

对第(1)(2)组集合，C⊂D 成立.

对于常用的数集，我们有如下的包含关系：

N ⊂ Z ⊂ Q ⊂ R.
