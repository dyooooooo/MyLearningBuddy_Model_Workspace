1.1 集合初步
例 6确定 x 与 y，使得集合 {2x, x+y} = {4, 8}.
解由集合相等的定义，可知 \begin{cases} 2x=4, \\ x+y=8 \end{cases} 或 \begin{cases} 2x=8, \\ x+y=4. \end{cases} 分别解得 \begin{cases} x=2, \\ y=6 \end{cases} 或 \begin{cases} x=4, \\ y=0. \end{cases}
