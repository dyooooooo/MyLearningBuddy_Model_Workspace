## 一、总体评价

成品线比原型成熟一个档次：原子写普遍、band_rules 阈值外用 yaml + 锁圈并发、注解只叠不改源、老 src 返回 410 并有测试钉死、XSS 转义有契约测试、实验线退役留了完整指路表。实验线 v5 的两个主要问题在并入时都治好了：图标不再丢（`_spare` 把没被收口行吃掉的图块补回流、`_rescue_missing` 兜底、实测 22 个已摄取页的图块 100% 被树引用）；同源碎片去重（`minted`）；树内阅读序按坐标排（`_order_members`）。

但四区扫描共约 95 条发现，其中**会出错级 12 条**。最要紧的三个主题：API 契约自相矛盾（GET 写盘、id 清洗两套）、最核心文件的写入反而最不设防（toc.json 非原子 + --book-id 无校验）、渲染层两个直开口子（行内图位置颠倒已被金样固化、table_html 全程无消毒）。

## 二、会出错（已抽查核实标 ✓）

### API 层（app/main.py + ir_lib.py）

1. **GET 有写副作用** ✓ — main.py:731 `ir_page_markdown` 用 `apply="fix"`，首次 GET 落盘 ir/pages/NNNN.json。同文件 library_page_md（:800）注释明说「只读请求不写正文」，IR 线自相矛盾；test_ir_routes.py:87 已把副作用固化进测试。
2. **book_id 两套清洗口径 → 500** ✓ — library.py:20 `_safe_id` 剔除式（`"a b"`→`"ab"`，可能撞上另一本书），ir_lib.py:43 `safe_book_id` 拒绝式（raise）。路由先过前者再过后者，畸形输入裸 500；且剔除式让不同原始 id 坍缩到同一本书。应统一拒绝式 + 400。
3. **toc 缓存命中与现算响应形状不一致** — main.py:705-711 缓存直出（无 `book_id` 键）vs :721 现算带 `book_id`。消费方按键取字段时两种响应不一样，无缓存分支测试。
4. **page_size 缺省与零宽除零** — ir_lib.py:574 缺省 [595,841]，真实页尺寸不同时 width_frac 静默算错；page_size=[0,800] 时 :648 除零。
5. **`int(page_idx)` 遇显式 null 抛 TypeError** — ir_lib.py:569 等，摄取整次炸掉；路由不捕 → 500。

### TOC 工具链（workspace/tools/）

6. **toc.json 非原子写** ✓ — build_toc.py:2398 `dest.write_text(...)`。同链 fill_unit_toc/ir_toc/ir_review/toc_extract 全是 tmp+replace，唯独这个每次全量重写、被当权威的核心文件不是。进程中断留半截 JSON。
7. **`--book-id` 无校验 + 空 id 静默选书** — build_toc.py:555-561 整条链唯一没套 safe_book_id 的入口，可路径穿越写出 workspace；book_id 为空时静默挑 is_default/字典序第一本——agent 漏传参数就改错书。
8. **resolve_printed_toc 双写中间态** — :424-475 先落一次盘，reconcile 分支再写，前次 payload 被丢；中间态短暂成为权威侧车，build_toc 并发读到按它建骨架。write_printed（:119）本身也非原子。
9. **fill_unit_toc 子串配页 + 400 页硬顶** — :343-356 两字以上的标题就拿去做子串匹配（「图」「实验」命中任意页），错配页码再经 median 扩散到全部回填；:161 印张页硬限 1..400，厚书静默丢页码。
10. **前置页扫描窗口三处不一致** — 16（resolve_printed_toc/toc_extract/build_toc）vs 24（ir_toc）vs 12/6（fill_unit_toc）。目录印在 17-24 页的书三线行为分裂。

### 渲染层（surfaces/page-ir）

11. **行内图并入位置颠倒，金样已固化** ✓ — render-page.mjs:98 `${extras}${inner}` 把并入的行内图拼在文本**前**；prevOk 情形（图在段后）渲到段首。cols-box.out.html 金样里 `<img>` 就在「通过图 1-13 了解过程。」之前——错误被金样钉成"正确"。
12. **table_html 原样注入 DOM** ✓ — render-page.mjs:155，MinerU v1 table_body 全程无消毒；全文件其余字段严格转义，唯独此口。paint 端点（main.py:1156）吃任意 payload，恶意 PDF 可经摄取管道把 HTML/JS 送进 kb-ui DOM。

### 前端（kb-ui）

13. **irLibrary loadPage 竞态** ✓ — irLibrary.ts:205-217 await 后裸读可变模块级 `activeId`，await 期间切书会把新书 blocks 填进旧书 shell。openBook（:220-256）同型；app.ts:536-546 旧面板同型——整条面板的系统性问题。
14. **IR 面板轮询空头支票** — 提示「识别完成后自动打开」，但 app.ts:643-660 startPoll 只看旧面板的 previewPages，IR 面板的书识别完永远不自动打开。live 事件也只刷旧面板（:667-721），IR 面板数据越放越旧；toc 失败结果被当空目录永久缓存（irLibrary.ts:94-96）。

## 三、隐患（选要）

- **v1 坐标系混用** ✓ — `_pair_by_center` 把 v1 bbox 与 layout PDF-point bbox 放进同一坐标系算中心距；model.json bbox 又是 0-1 归一化。测试自带数据（[142,625,616,758] 超 595 页宽）证明 v1 是另一套坐标，目前靠最近邻容忍侥幸配对，换书即可能错配。建议单位检测或值域断言。
- **stale remap.json 不清理** ✓ — ingest_layout.py:161 `if remap:` 只在非空时写，上次运行的 remap 本次为空时残留，消费方拿过期映射当最新。
- **栏目头条目重叠 → 文本彻底消失** — ir_lib.py:707-718 重叠则不提升 + :836-837 又一律跳过，既不在 blocks 也不在 chrome。
- **block_id 冲突静默覆盖** — sha16 网格盐对同页无文本装饰图/同文近位块会撞 id，`raw_by_id`/注解 `by_id` 都是 dict，注解永远只能打到其中一个块。
- **model.json 按位置对齐**（`model[page_no-1]`）无交叉验证，缺页/乱序时 latex 静默错位。
- **跨页块只打标不缝合**，无测试覆盖，消费方需自知。
- **tree kind 未转义进 class 属性**（render-page.mjs:312,343）；树覆盖问题渲染器零设防（漏块静默消失、重复块渲染两遍），与 paint 开放端点组合起来不稳。
- **页码基准混用**：1-based/0-based 五处手算 `page_no-1`；页码宽度 `\d{1,3}` vs `\d{1,4}` 不一致，>999 页的书目录条目静默丢失。
- **ir_toc 回填猜测写成确定值**（:394-400）：无 pdf_page 的前置条目被错标到后面章节的页。
- **toc_lexicon 每次调用重读+sha256 整个 YAML**（:84-100），几千行目录就是几千次文件哈希；全局缓存无锁。
- **网关 /proxy/ir 无白名单**：编码穿越 `%2F%2E%2E` 原样透传到 agent；`path.startswith("ir?")` 是死代码。
- **结构化库不独立**：openBook 靠旧线 `kb.get` 的 status 决定可用性，IR 已生成但旧线 convert 失败的书同样打不开。

## 四、整洁（选要）

- **死配置**：六份 manifest.yaml 无消费者（surfaces.py 硬编码文件名，page-ir 的 `entry: prepare.mjs` 还误导——主路径是 paint.mjs）；compare/profile.yaml `default_mode` 是死的。
- **死 CSS**：page-ir/theme.css 约 130/323 行（40%）是退役 band-class 时代残留，`.kb-ir-band-col--plate` 还是现役类的旧错名。
- **同一 IR 两套 HTML 生成器**：ir_lib.py:955-995 内联百分比 vs render-page.mjs 的 --kb-wf/cqi，类名相同机制不同，两条读页路由产出不同 markup。
- **平行重复**：kb-ui app.ts vs irLibrary.ts 约 150 行近乎逐行重复；escapeHtml 四份逐字拷贝；safe_book_id/atomic_write 三份拷贝；kb-page-toc HTML 正则四份近似但漂移（文档自称"镜像须一致"）。
- **img span 机制疑似死路**：`spans_from_block` 产 `{"t":"img"}` span，但抽 22 个已摄取页，收口行 img span 数全 0——图标实际走 `_spare` 补回。要么删掉，要么补一个能触发它的金样。
- **测试基建**：pytest 需 `PYTHONPATH=.` 但仓库无配置（pyproject/pytest.ini/conftest 都没有），裸跑 52 个收集错误——一行配置的事 ✓（实测）。test_page_ir_render.py:30 驱动传 `bookId` 为对象、生产是字符串，asset URL 路径实际没被测。test_ir_bands 依赖本机真实书数据，缺书时**红而非 skip**（有意设计，但容器/CI 里要注意）。
- **schema.md 漂移**：type 枚举含 code（双侧无实现）；inline_image 条件不全（漏宽<12%）；未区分渲染契约与摄取留痕字段。box_kinds.yaml「思考与讨论」重复两行。
- **band_rules.yaml 热改承诺对 INDENT_PX 不成立**：渲染端 render-page.mjs:87 硬编码 12。
