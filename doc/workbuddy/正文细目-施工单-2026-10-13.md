## 2 · 一个必须知道的前提

正文页 IR 标题块**自带** `level`，但 MinerU 在正文页一律给 `2`：

```
type=title kind=body level=2 text=1.2 直线的方程
type=title kind=body level=2 text=1 几种特殊形式的直线方程
type=title kind=body level=2 text=(1) 直线的点斜式方程
```

→ **层级只能从"编号形态"推，不能读 IR。** 这是本补丁的技术核心。

# 脚注标记：LaTeX 上标 `$^{①}$` / `^{①}`，或贴在中文/右括号后的尾随圈码 `①`。
_FOOTNOTE_TEX = re.compile(r"\$\^\{[^{}]*\}\$|\^\{[^{}]*\}")
_FOOTNOTE_TAIL = re.compile(
    r"(?<=[\u4e00-\u9fff\u3001\u3002\uff09\uff1a\u201d\u300b\uff3d])\s*[\u2460-\u2473]\s*$"
)


def _strip_footnote(text: str) -> str:
    """剥掉脚注标记。显示标题与比对键都用剥后的文本。

    不剥的话 `《论语》十二章$^{①}$` 会与骨架行 `5 《论语》十二章` 比对失败，
    父行标题被重复挂一遍（实测语文各册共 143 条受影响）。
    """
    out = _FOOTNOTE_TEX.sub("", text or "")
    prev = None
    while prev != out:
        prev = out
        out = _FOOTNOTE_TAIL.sub("", out)
    return out.strip()
```

> 尾随圈码只在**前一个字是中文/右括号**时才算脚注，所以列表编号开头的
> `① 直线的倾斜角` **不会**被误剥（自检已覆盖）。

```python
# 细目层级只看编号形态。正文页 IR 块的 `level` 恒为 2（MinerU），不可用。
_KID_NUM: list[tuple[re.Pattern[str], int]] = [
    (re.compile(r"^[\uff08(]\s*(?:[0-9\uff10-\uff19]{1,2}|[一二三四五六七八九十]{1,3})\s*[)\uff09]"), 2),
    (re.compile(r"^[\u2460-\u2473]"), 3),
    (re.compile(r"^[0-9\uff10-\uff19]{1,2}(?:\.[0-9\uff10-\uff19]{1,2}){1,2}(?=[\s\u3001\uff0e.]|$)"), 1),
    (re.compile(r"^[0-9\uff10-\uff19]{1,2}(?=[\s\u3001\uff0e.])"), 1),
    (re.compile(r"^[一二三四五六七八九十]{1,3}[\u3001\uff0e.]"), 2),
]


def _kid_level(title: str, base: int, prev: int | None) -> int:
    """按编号形态定细目层级。`base` 是骨架行的绝对层级。

    `1 xxx` -> base+1；`(1)` / `（一）` -> base+2；`①` -> base+3；
    无编号 -> 跟随上一条兄弟（不比它深）。
    这样 `1 → (1) → (2) → 2` 里第二个 `1` 秩的条目回到 base+1，不会一路加深。
    """
    for pattern, rank in _KID_NUM:
        if pattern.match(title):
            return base + rank
    return prev if prev is not None else base + 1
```

def _body_kids(
    rows: list[dict[str, Any]],
    titles: dict[int, list[dict[str, Any]]],
    last_page: int,
) -> list[list[dict[str, Any]]]:
    """老线挂细目：从这一行的页到下一行开始之前，没进骨架的正文标题挂在这一行下面。

    细目层级不能读 IR 块的 `level`（正文页 MinerU 一律给 2），只能从编号形态推。
    """
    seen: set[str] = set()
    out: list[list[dict[str, Any]]] = []
    for index, row in enumerate(rows):
        kids: list[dict[str, Any]] = []
        base = row["level"]
        prev_kid_level: int | None = None
        start = row["pdf_page"]
        end = next((r["pdf_page"] for r in rows[index + 1 :] if r["pdf_page"]), last_page + 1)
        for page_no in range(start, end) if start else ():
            for item in titles.get(page_no, ()):
                if any(_same_title(item["key"], other["key"]) for other in rows):
                    continue
                title = _keep_heading(item["text"], seen)
                if not title or toc_lexicon.is_kids_noise(title):
                    continue
                level = _kid_level(title, base, prev_kid_level)
                prev_kid_level = level
                kids.append({
                    "level": level,
                    "title": title,
                    "print_page": item["print_page"],
                    "pdf_page": page_no,
                })
        out.append(kids)
    return out
```
