## 一、结论：两个问题都落在同一个函数的同三行里

**唯一落点**：`agents/textbook-agent/workspace/tools/ir_toc.py` → `_body_kids()`（约 871-899 行）

```python
for page_no in range(start, end) if start else ():
    for item in titles.get(page_no, ()):
```

| 代码 | 造成的现象 | 对应你的问题 |
|---|---|---|
| 噪声闸门过窄 | `练习1.1` / `习题1.1` / `A组` / `B组` 全被当小标题 | 问题 2 |
| `level = row.level + 1` | `1` / `(1)` / `(2)` / `2` 全部拍成同一级 | 问题 2(b) |
| 标题文本直取 IR 标题块 | 折行拆条、脚注标记混入、层级无从判断 | 问题 1 |

### 一个必须知道的前提：IR 的 `level` 字段是废的

IR 标题块**自带** `level`，但正文页里 MinerU 一律给 `2`。实测 `1.2 直线的方程` 那一页：

```
type=title kind=body level=2 text=1.2 直线的方程
type=title kind=body level=2 text=1 几种特殊形式的直线方程
type=title kind=body level=2 text=(1) 直线的点斜式方程
型⋯ page 15: type=title kind=body level=2 text=练习1.2(1)
型⋯ page 15: type=title kind=body level=2 text=(2) 直线的两点式方程
型⋯ page 17: type=title kind=body level=2 text=2 直线的一般式方程
```

**所以层级只能从「编号格式」推，不能指望 MinerU。** 这是本提案的技术核心。

## 四、提案（三层，逐层可独立验收）

### P0 · 确定性修（改 `_body_kids`，不调模型）★ 建议先做

**三件事：**

1. **噪声闸门** —— 候选细目先过「栏目 / 练习」判定，命中即丢
   - 复用已有 `toc_lexicon.is_column_label()`（23 个栏目名已在 `configs/toc_lexicon.yaml`）
   - 新增「练习 / 习题 / 例题 / 复习题 / A组 / B组 / 内容提要 / 阅读与思考 / 探究 / 活动 / 数学探究 …」
     写进 **`configs/toc_lexicon.yaml`**（保持单一数据源，JS 侧同源）
   - ⚠️ 按仓库家规：加词法规则**必须同时在 `tests/test_toc_lexicon.py` 补样例**（Python / JS 双跑一致）

2. **编号定层级** —— 不再一律 +1

   | 标题形态 | 相对深度 |
   |---|---|
   | `1 xxx` / `1.1 xxx` / `一、xxx` | +1（节下第一层） |
   | `(1) xxx` / `（一）xxx` | +2 |
   | `① xxx` | +3 |
   | 无编号 | 跟随上一条兄弟；且不得比它深超过 1 |

   用「编号栈」保证 `1 → (1) → (2) → 2` 的起伏正确（`2` 要回到 +1，不能继续加深）。

3. **标题清洗** —— `_title_key` / `_same_title` 先剥 `$^{..}$` 脚注标记
   → 同时修掉「父行标题被重复挂载」
