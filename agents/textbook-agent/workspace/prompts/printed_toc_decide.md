这是一本教材印刷目录的一页图片，以及程序从这页取出的编号行。

字段：
- n：编号
- text：这一行的文字
- page：行尾的页码，程序没读到就是 null
- x：这一行文字的左边缘
- style_level：程序按印刷字号、粗细、缩进算出的层级。只有电子文字层的页才有，扫描页为 null

对每一个编号行回答：

- continues：这一行是不是上一行同一条标题的「下半句」——上一行的标题文字太长，剩下的字被折到了这一行。只有文字被截断时才算；独立的条目、子条目、作者行、分项都是 false。
- level：这一行（或它所属的那条标题）在目录树里的层级。最外层是 0；图上从属于上一条的条目比它深 1。只看图上的版式：字号、颜色、缩进、编号样式相同的条目同级，不要按词义猜。style_level 是印刷事实，和图上一致时照用；图上明显不同才改。continues 为 true 的行写和上一行一样的层级。
- page_printed：图上这一行的右边（或行尾）有没有印页码。
- split：这一行在图上其实是两条独立的条目被拼在了一起时，写出拆开后的各段（连起来必须等于原文字，不改字、不补字）；否则不写。

页的开头若接着上一页的结构，按「上一页结尾」给的层级接上。每个编号都要回答，按原顺序。只输出 JSON。
