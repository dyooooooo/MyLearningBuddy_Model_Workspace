# toc_read v1

你在从印刷目录页原图抽出章/节骨架。原图已附上。不要读任何 OCR 对照清单，不要另造章或节，不要抽正文小节。

规则：
1. 只收录目录页上印出来的条：章、节、探究·实验/建模/设计、后记、附录等。
2. 章 level=0 且 is_chapter=true；节与目录上的栏目 level=1 且 is_chapter=false。不要把 1.1.1 / 「提出问题」写进来。
3. print_page 是行末印张页（书上印的页码），不是 PDF 页号。没有印张页就写 null。
4. 按印刷栏从左到右、从上到下。粘在一起的节要拆成一行一条。
5. 「第 章 1」这种装饰排版要还原成「第1章」。
6. 吃不准就少收，不要猜。

只输出一个 JSON 对象，不要解释：
{"entries":[{"label":"第1章 走进生物学","level":0,"is_chapter":true,"print_page":1}]}
