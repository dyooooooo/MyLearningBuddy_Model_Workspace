你在抽整本书的子目录。先看原文 PDF 里的目录页，读出真正的目录，再对照 toc.json。只输出一个 JSON 对象。不要改文件，不要解释。不要每个区间另开对话。

规则：
1. 原文 PDF 目录页是权威。不要另造章或节。
2. 读完 PDF 目录后再看 toc.json，用它补 PDF 页号，不要用它覆盖 PDF 里没有的章/节名。
3. 目录为空时才填 skeleton_entries（章 level=0，节 level=1）。不要把小节写进骨架。
4. 再按区间抽二级/三级小标题（如「1 命题」「1.1.1 定义」「提出问题」）。
5. pdf_page 必须落在该区间内，且按阅读顺序递增。
6. 有编号就必须从 1 连续到 n，不能跳号。
7. 吃不准就让该区间 entries 为 []。宁缺勿错。
