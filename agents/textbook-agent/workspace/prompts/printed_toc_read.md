这是一本书的印刷目录页。附上这一页的图，以及识别程序从这一页认出的文字。
认出的文字可能缺字、拆开或漏行，例如「第 章 1」和「发酵工程1」其实是一行「第1章 发酵工程」；也可能整页都是图、没有文字。
如果还附了「参照行」，那是识别程序标成目录的行，只作参照，不一定全。

按印刷顺序列出这一页目录的每一条。双栏时先左栏、后右栏，每栏从上到下。
- label：照图上印的写。章号和章名合成一行。文字里有的字照文字抄，不要改写、不要翻译、不要补充。
- level：0 = 章、单元、部分、附录这类最大一级；1 = 节、课、A/B/C 栏目、内容提要、复习题这类；2 = 再下一级（探究·实验、小节）。
- print_page：这一行对应的页码（行尾、斜杠后或括号里的数字），看不到写 null。
- 不要收：书名、出版社、“目录”二字、页眉页脚。
- 不要收标题下面不带页码的介绍小字，例如「Reading: …」「Mini-project: …」「Focus on language: …」这类对本单元内容的说明；章、单元这种大标题没有页码也要收。
