# 一页教材 → HTML 嵌套盒子

输入是一页扫描稿：每个块、子块、行、小片段（span）都有坐标和类型。  
输出是一棵 **HTML 盒子树**，用 CSS 排：上下叠、左右并、里面再套。

不分书、不写死几栏、不预先命名「栏目 / 正文」。先投出**整页栏轨**，再把每条横带坐上去。空着的那一轨是对齐用的空格子，不是树上另设的「栏缝」节点。

下面八步是通则。生物第 9 页、化学第 8 页、化学第 13 页、数学第 11 页只是同一套规则的四个例子。

算法本身零写盘。写中间表示（IR, Intermediate Representation）的 `ir/pages` 是 `ingest_layout`；老线的 `pages/`、`mid/` 一行不动。成品格式 `nested_bands_v3`。

阈值全在 `workspace/ir/band_rules.yaml`，不按书名写死。改完不重建镜像，下次 `ingest_layout(..., apply=fix)` 即生效：

# 树上有什么

```html
<div class="page">
  <!-- 页眉、页码在外面 -->
  <section class="band">          <!-- 占满内容区宽度的一条 -->
    <div class="cell">…</div>    <!-- 正文轨或侧栏轨上的格子 -->
    <div class="cell blank"></div>
  </section>
  <section class="band">
    <figure>                     <!-- 占一轨，或真跨两轨 -->
      <div class="panel"><img /><figcaption>单张说明</figcaption></div>
      <figcaption class="shared">整行题注</figcaption>
    </figure>
  </section>
</div>
```

| 人话 | CSS |
|---|---|
| 页 | 最外层盒子，只装内容区 |
| 栏轨 | 整页共用的正文轨、侧栏轨。每条带都往这套轨上坐 |
| 横带 | 纵向排列的 `section`，一条接一条，中间不留洞 |
| 并排孩子 | 这一条里的格子；通常是正文轨加侧栏轨，空的那格仍占着 |
| 包含 | 小框大部分落在大框里，就是孩子 |

页眉、页码、页眉上的小标不进这棵树。

# 八步

## 1. 铺框

把块、子块、行、小片段都铺成占位框。图里的图身、题注同样铺。只认坐标和类型，不猜角色。

## 2. 丢掉非本页

标了跨页、或坐标已经跑到下一页顶、或行/小片段大半不在父块里的，本页不要。父块框也裁到本页，不要把本页盒子撑到下一页。

## 3. 页眉页码出树

废弃块里的页眉、页码拿出去。正文还没开始时的小标也拿出去。

## 4. 认图组（不是通用父子树）

这一步只处理图，不给正文建父子树。文件里拆开的图身子块、题注，坐标还在图里，仍算进这一团。

图和旁边的图在同一横条上靠近，先合成一行图，再在**里面**拆。矮的说明碰到图，并进图。图和上面的正文重叠，把图的顶往下推，不要把正文吃进去。

## 5. 横切横带

先用通栏块切开，剩下的段再按「列结构合不合得来」切开。

**通栏**＝宽度占版心 85% 以上的块，或宽度占页宽 20% 以上的图段。
认定通栏之后，它**向上吞并**紧贴（垂直间隙 ≤ 28）且横向完全落在它范围内的小块。
已经和旁边并排的块不吞。上方若已经是两列，整段不吞。总高度有上限。
一个视觉上的栏目框在数据里是好几个平行块、没有外框，靠这一步收回同一条带。只靠几何，不认栏目文字、不认书名。

其余段落先按紧贴（垂直间隙 < 8）叠成小包，再决定相邻两包要不要并成一条带：
垂直间隙 < 80，并且列结构一模一样，或者两包横向并排，或者两包左右错开可以坐进同一条带的两轨（史话头：左图标加标、右小节题）。紧贴的续段（间隙 < 8）即使列数变少，也并回上一条。

横带占满内容区宽度。上面一条的底对着下面一条的顶。

## 6. 先投栏轨，再把带落到轨上

整页只投一次栏轨，不扫白缝。

- 正文轨＝墨最重那条 pair 带里最宽的一列
- 侧栏轨＝版心的另一侧，内缘取该侧根块的实测外缘
- 侧栏在左还是右，看正文轨离哪边远
- 投不出第二轨，退回单轨

每条带按栏轨发格子：**一轨一格**。空轨发空格子，用来对齐，不是边角料。
块完全落在侧栏、且和正文轨之间真有一列空隙（> 14）的，进侧栏。
骑在缝上的（练习左列从 88 起叠进空着的左轨）仍归正文轨。

真跨两轨的图（两轨都有图面板）或通栏正文，发一格 `span`，不硬切进正文轨。
只占一轨的图，显示框裁到该轨，对面轨留空。

## 7. 孩子里面再套

先把一格里的成员按坐标分上下行：竖向重叠过半、横向不相撞的算**同一行**。
同一行的标题合成一段。小图标跟它旁边那块就是这么判到一起的，跟数组先后无关。

写段时和所在格求交。越界的记 `raw_union`，`crop` 标明裁到哪一轨。

- 文字、标题的**显示框**裁到轨（化学 8 题头右缘 470 裁到 379），裁前框记在 `raw_union`
- 图面板**不裁到栏轨**（化学 13 左面板 122 可以伸进侧栏）；`nest_figure` 里图身用原 bbox

**标题**  
第一行相对装着它的那一格：两侧留白都够宽且差不多 → 居中；否则靠左。只有这两种。

**正文**  
正文不判对齐，只判缩进。缩进是列内相对关系聚成的 0 / 1 / 2 级，不是像素。

- 段首缩进 ＝ 首行 x0 − 块 x0
- 整段缩进 ＝ 块 x0 − 这一列正文左缘

取大的那个，再按列聚簇编号。折行且量为 0 的段，按这一列单行块的档位补齐。

**图**

| 是什么 | 怎么认 | 放哪 |
|---|---|---|
| 图身 | 类型是图身 | 这一张面板里 |
| 单张说明 | 左右只叠在这一张图身下 | 这张面板底下 |
| 整行题注 | 叠过两张及以上，或整行底下那条宽题注 | 这一行图最下面，不跟单张说明混 |

有的面板没有说明，空着。文件里拆出去的那段字，坐标还在图里，仍是图的孩子。

**练习那种多列窄块**  
几列都落在**同一个**孩子里，再在这个孩子里面横切列。一列在侧袋、一列在正文，不是这种。

不要做成从页顶穿到页底、穿过图的大框。

## 8. 文字收口

套完盒子之后，给每段字打类型，类型相同的按原来的位置合成大块。图怎么收成一组，这一步不动。

类型只看已经有的位置框、印刷角色、以及套好的栏格，不认书名，不看文件顺序。

- 先看落在哪一栏：正文轨是正文，侧栏在左是左、在右是右。骑在栏缝上的仍算正文。
- 侧栏格里有标题（或小图标加字）→ 这一格是对话。同一条带的正文格里只有标题、没有长段落 → 这个标题也是对话。下面一条的字，左缘贴着这块对话 → 还是对话。
- 类型相同才能合成一块。对话和对话合成一块对话；正文和正文合成一块课文，中间若隔着图就拆开。
- 合成时从上到下认行。同一行左右两截写成一行，中间用制表符隔开，不再拆成两个块。同一条带里左边栏目名、右边小节题，也写成一行制表符。
- 扫描稿原文里的制表符先换成空格。成品里的制表符只表示收口合成的两栏。
- 每段仍带着原来的位置框；裁过的把裁前的框也留下。大块自己有一个外包框。

出门多一份 `units`。给人看的页按这些大块出字；图仍走原来的格子。

# v2 删掉了什么

原型 `containment.py` 里这些函数连带「栏缝」这个概念一起删了：
`_narrow_roots`、`_column_bodies`、`_drop_fake_gutters`、`_pack_tracks`、`_cols`、`_main_col`、
`choose_tracks`、`_slot`、`_true_side`、`_is_grid`、`_mode`。

它们做的是同一件事：整页先找一条纵向空白当栏缝，把版心切成左右两栏，
再让每条带、每个块都按这个页级结论站位。一页只要有一处侧袋，
整页都被按「正文 ＋ 侧袋」切，没侧袋的带被迫留一个和侧袋一样宽的大空框。

v2 把「列」这个结论降到**带**一级（`band_columns`），
缝退化成一个空格子（`fill_band`），通栏改成看宽度占比加向上吸附（`is_span_block` / `absorb_above`）。

# v3 请回来的是栏轨，不是白缝扫描

v3 的 `page_tracks` 约几十行，**不扫白缝**。正文轨取墨最重 pair 带里最宽的一列，
侧栏轨取另一侧根块的实测外缘。`band_columns` 只给投轨用，不再给每条带各自发列。

请回来的是「整页共用一套栏宽」这个概念。v2 删掉的白缝扫描不会回来。
`fill_band` 按轨发 `main` / `aside` 格子；真跨两轨才发 `span`。
