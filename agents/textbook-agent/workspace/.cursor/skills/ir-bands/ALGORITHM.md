# 一页教材 → HTML 嵌套盒子

输入是一页扫描稿：每个块、子块、行、小片段（span）都有坐标和类型。  
输出是一棵 **HTML 盒子树**，用 CSS 排：上下叠、左右并、里面再套。

不分书、不写死几栏、不预先命名「栏目 / 正文」。先量整页宽度，缺的地方补空白格；Y 上重叠的块分成 N 栏。图段横向长成占满页宽的大盒子，文字（和空白）纵向长、停在图段处。盒子套好之后，正文才按标题/缩进做逻辑格式化，侧栏不再特殊排。

下面八步是通则。生物第 9 页、化学第 8 页、化学第 13 页、数学第 11 页只是同一套规则的四个例子。

算法本身零写盘。写中间表示（IR, Intermediate Representation）的 `ir/pages` 是 `ingest_layout`；老线的 `pages/`、`mid/` 一行不动。成品格式 `nested_bands_v3`。

阈值全在 `workspace/ir/band_rules.yaml`，不按书名写死。改完不重建镜像，下次 `ingest_layout(..., apply=fix)` 即生效：

# 树上有什么

```html
<div class="page">
  <!-- 页眉、页码在外面 -->
  <section class="band">          <!-- 占满内容区宽度的一条 -->
    <div class="cell">…</div>    <!-- 正文轨或侧栏轨上的格子 -->
    <div class="cell blank"></div>
  </section>
  <section class="band">
    <figure>                     <!-- 占一轨，或真跨两轨 -->
      <div class="panel"><img /><figcaption>单张说明</figcaption></div>
      <figcaption class="shared">整行题注</figcaption>
    </figure>
  </section>
</div>
```

| 人话 | CSS |
|---|---|
| 页 | 最外层盒子，只装内容区 |
| 栏轨 | 整页共用的正文轨、侧栏轨。每条带都往这套轨上坐 |
| 横带 | 纵向排列的 `section`，一条接一条，中间不留洞 |
| 并排孩子 | 这一条里的格子；通常是正文轨加侧栏轨，空的那格仍占着 |
| 包含 | 小框大部分落在大框里，就是孩子 |

页眉、页码、页眉上的小标不进这棵树。

# 八步

## 1. 铺框

把块、子块、行、小片段都铺成占位框。图里的图身、题注同样铺。只认坐标和类型，不猜角色。

## 2. 丢掉非本页

标了跨页、或坐标已经跑到下一页顶、或行/小片段大半不在父块里的，本页不要。父块框也裁到本页，不要把本页盒子撑到下一页。

## 3. 页眉页码出树

废弃块里的页眉、页码拿出去。正文还没开始时的小标也拿出去。

## 4. 认图组（不是通用父子树）

这一步只处理图，不给正文建父子树。文件里拆开的图身子块、题注，坐标还在图里，仍算进这一团。

图和旁边的图在同一横条上靠近，先合成一行图，再在**里面**拆。矮的说明碰到图，并进图。图和上面的正文重叠，把图的顶往下推，不要把正文吃进去。

## 5. 量页宽，补空白

画布是整页 `[0, 页宽]`。每一行里的块如果没占满页宽，左右（或栏缝里）生成空白格，把这一行铺满，**立刻和原栏封成一个大块**。窄缝只并进空白栏，不把字栏拉宽。之后只许整栏长高，不许丢掉空白再重铺。

## 6. 盒子生长：图横长，字纵长

不再整页先投一次栏、默认进正文。从原始块往外长成套着的大盒子。

**Y 重叠就是并排。** 同一横条上两个块重叠，就是两栏；三个块就是三栏。只看这一横条，不把下面右栏的东西算进上面的正文。

**图段只横向长。** 同一行的图合成一个大盒子，两边用空白补到页宽。图段把上下文字隔开，所以是横切带。只趴在侧栏、旁边才是正文的小图，不横切，跟着侧栏一起纵向长。

**文字优先纵向长。** 原来的块还在原来的位置。上下两个大块只有指纹相同才往下长：栏数一样、空对空、字对字，且每一栏宽度占比差不超过 `SIG_RATIO_TOL`（占页宽 10%）。合并后上下两行变成一排更高的左右栏。结构不同（上是空|字、下是字|空）或比例差太多（很宽+一条缝 对 各占一半）就分成两个大块。`PAIR_GAP` 只表示竖向挨得近，不能单独批准合并。碰到图段就停。只有一块的时候才单独占一行。

盒子套好之后才认正文轨：在已经长好的文字格里，取墨最多、又不是通栏宽的那一列。格子跟这条轨重叠的是正文，否则是侧栏。侧栏在左还是在右，看侧栏中点在正文中点的哪边。生长过程中不预投栏、不把字钉到正文轨上。

## 7. 盒子套好之后才格式化

图不再把同格的字吃掉。同一格里落了好几组图，每组都出段，不是只留最大的那组。

**正文格**按阅读顺序出段：标题靠左，缩进仍是列内 0 / 1 / 2 级，不拿坐标去挪位置。格内竖向压在一起的几块仍按第 6 节分成并排的列，不叠在同一个框里。

**侧栏格**块留在原位，不做标题居中、不做缩进分档。

**图**仍按面板拆：图身、单张说明、整行题注。图身框不裁到栏轨；并排面板之间那道空当也算一列空白。题注跟着图走，图探出格子时题注不硬塞回格子。

**空白最后统一补。** 一格的段全部出完之后，才按这些段反推没被占住的竖向空档，一律补成空白段；兜底块插回来之后，横带之间裂开的缝同样补成整页宽的空白带。所以空白不是残留，是按内容重算出来的，格子里不留洞。

## 8. 排版不合并原始块

每个叶子装的就是落在它里面的原始块下标。块内的多行由块自己的 `lines` 合并，这一步不再造派生块，也不再出 `units`。

题注是唯一的例外：被吸进图里的源块不再单独成段，字随图走。认题注要同时过文字关和几何关——

- 文字：`图 1-2` 这类编号开头、或整块括起来的短标记直接算；其余不能是小节标题、不能是题号选项、不能写成一整句（半角句点也算句末），且不长过 `CAPTION_MAX_CHARS`。
- 几何：横向得压在图宽里；没写题注记号的短句更严，整块都要落在图宽以内，向左或向右探出图外的就是版心里碰巧挨着图的一行正文，不能吃。

老页里可能还留着 `kb-close-*` 派生块，只作兼容读取，新导入不再生成。

# v2 删掉了什么

原型 `containment.py` 里这些函数连带「栏缝」这个概念一起删了：
`_narrow_roots`、`_column_bodies`、`_drop_fake_gutters`、`_pack_tracks`、`_cols`、`_main_col`、
`choose_tracks`、`_slot`、`_true_side`、`_is_grid`、`_mode`。

它们做的是同一件事：整页先找一条纵向空白当栏缝，把版心切成左右两栏，
再让每条带、每个块都按这个页级结论站位。一页只要有一处侧袋，
整页都被按「正文 ＋ 侧袋」切，没侧袋的带被迫留一个和侧袋一样宽的大空框。

v2 把「列」这个结论降到**带**一级（`band_columns`），
缝退化成一个空格子（`fill_band`），通栏改成看宽度占比加向上吸附（`is_span_block` / `absorb_above`）。
