# 戏剧对白

原书话剧把角色名放在左侧约三四个字宽，台词从右侧起排，折行仍对齐台词；括号里的动作夹在名字和台词之间；开场说明左右都缩。用 `tag_drama(book_id)`，不要手写一书，也不要收成表格。

中间文件只写围栏：

```text
::: kb-stage
午饭后，天气更阴沉，更郁热……
:::

::: kb-drama
周朴园（点着一支吕宋烟，向侍萍）这是太太找出来的雨衣吗？

鲁侍萍 （看着他）大概是的。
:::
```

源页仍是官方 Markdown：一行「角色名 + 可选（说明）+ 台词」。点线、悬挂对齐、角色加粗由 page-body 读页时画。不要把 `class` 或 `<table>` 写进书页。

杂剧「（角色云/唱）」和「【曲牌】唱词」也收进 `kb-drama`，不当表。

## 何时调

- 语文版式任务之后（事件 `task.chinese-textbook-layout.completed`）。
- 科目是 chinese 且类型是 textbook。
- 没有连续对白或两列角色/台词表就停。英语、数学不调。

## 工具已经做的

- 认「角色名 + 空格或（说明）+ 台词」、（云/唱/科）、【曲牌】。
- 两列短角色名/台词 HTML 表拆回围栏。
- 开场说明收成 `kb-stage`。
- 经闸门 `write_mid`，印章一起更新。
- 封面、目录、页注、学习提示不收。

## 不要做

- 不要改 `tag_chinese_layout` / `build_toc` / `improve_render`。
- 不要对目录页 unwrap。
- 不要把古文或诗行收进戏剧围栏。
- 不要贴整页正文。
- 不要直接改 `mid/*.md`（不走闸门会被版式任务冲掉）。
