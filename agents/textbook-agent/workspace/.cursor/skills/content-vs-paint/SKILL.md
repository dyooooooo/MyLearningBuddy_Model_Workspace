# 中间表示两层：编译 / 表达

Python 只跟原始文件和中间文件之间打交道（或者它读中间文件），不会做显示层的事儿。

显示层（前端）只读中间文件，不读原始文件，通过中间文件来进行显示，也不会做内容的事儿。

这不是 MVC。更接近编译器：原始文件编译成中间表示，再按中间表示画出来。

以后不允许再出现以下情况：

1. 将表达层放到 Python 里；
2. 将内容的生成放到前端。

## 两层

| 层 | 谁 | 只做什么 | 不做什么 |
|---|---|---|---|
| 编译 | Python | 原始 `mineru/` → 中间 `ir/`；或读 `ir/` 再写另一份 `ir/`（目录、待审、换号、注解） | 不算字号、行距、折行，不画页 |
| 表达 | 前端 JS | 只读 `ir/` 再画：页读 `pages`，目录读 `toc.json`，印刷目录页读 `print_toc.json` | 不摄取、不写 `ir/`、不读 `mineru/` |

中间文件是整棵 `ir/`：`pages/`、`toc.json`、`print_toc.json`、`notes/`、`review.json`、`remap.json`。`fonts.json` 是旧字号表，不算内容。

开闭：新书走同一套中间文件形状。新显示规则只改 `page-ir`；新内容字段只改编译。

第一性：一件事一个地方。印刷行 = 中间页 `lines`。字号、行距、折行 = `render-page.mjs`。行距用框高除以印刷行数，后几行可以没字。侧栏位置写在块的 `slot` 上（`main` / `aside` / `span`），墨稿读 `slot` 着色；旧页没有 `slot` 才猜框。树不写盘。矮框题注、表注、页脚注一律按一行算字号，留白三成，不按折行摊高。高框页脚注按行数摊高，再缩小到宽和高都进自己的框。同一页的页脚注共用该页能装下所有注的最小字号再减一，不跟全书一张票。页脚注行距固定为 12.5。页脚注在框内折行，不锁成 nowrap，字不许伸出右沿。同一页同一类共用全书那一票，不按每一块的框再改字号。行框高过 40 的标题不参加投票。虚线框里的标题不加粗。拉丁字母和汉字都用思源黑体这一套，和改字体之前一样。高框图注仍按折得开的行数摊。表格字必须装进格子和外框：按列宽和框高从大往小试字号，公式一行装不下就再缩小，不许画出格。有图的列分宽一些，装得下时优先少折行。带图的表不算图行高。表内图片只放行 img，src 改成资源地址，不把整张表转义成字。每张表、每条题注用自己摊出的字号，不全书一张票盖掉另一张。
