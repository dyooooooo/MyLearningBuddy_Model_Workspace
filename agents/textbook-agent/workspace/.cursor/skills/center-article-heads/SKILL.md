# 课文标题和作者

目录最后一级是「篇名 / 作者」时，正文里标题和作者都要保留。标题用 `##`（加粗、与其他课文同字号），作者单独一行写在标题下面。用 `center_article_heads(book_id, apply=fix)`，不要手写一书。

不为居中往书页或渲染里加 HTML。居中围栏只写 `mid/`，见 `page-layers`。带 `style=` 的标签会被公式保护吃掉。用户已明确：不要为居中改 `page-body`。

## 何时调

- `fill_unit_toc` 之后（事件 `tool.fill_unit_toc`）；没有「第N单元」但 toc 末级已是「篇名 / 作者」时，在 `build_toc` 之后手调。
- toc.json 里出现「篇名 / 作者」。
- 没有该形状就停。英语、数学等不调。

## 工具已经做的

- 只认 toc 里带 ` / ` 的末级条目。
- 在对应页找标题行和紧随的作者行；中间可有以「——」起头的副标题、括号年月日。
- 写成 `## 篇名` 和下一行作者。旧的 `kb-article-*` HTML 收成这种写法。
- 原是普通段落的篇名也抬成 `##`。已是该形状的不改。不另编标题、不删作者。
- 目录页、学习提示、阅读指导、单元学习任务不改。

## 不要做

- 不要改 `page-body` / `build_toc` / `fill_unit_toc` / `improve_render`。
- 不要对目录页 unwrap。
- 不要把正文小节标题、图说、题词当成篇名。
- 不要贴整页正文。
