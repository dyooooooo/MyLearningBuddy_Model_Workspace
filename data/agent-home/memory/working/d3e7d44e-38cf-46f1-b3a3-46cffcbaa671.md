最后思考/作答：
**正文缩进没有写进书页 HTML。** 书页就是普通段落，没有全角空格，也没有 `<p style="text-indent">`。

画面用 CSS：`p { text-indent: 2em }`，每个**段落**首行缩两字。Markdown 段落渲染时本来就会变成 `<p>`，和标题变成 `h2` 一样，不是另加一套标签。

列表、表注、题解在渲染时会套已有的 `kb-list-item` 等 class，并把缩进关掉，避免跟正文抢。这些是原来就有的，不是为居中新加的。

另外：只缩**段首**，不是每个句子的句首。句句缩进书上一般也没有，这边也没做。
