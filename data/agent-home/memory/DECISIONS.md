# 跨对话结论

只追加以后都成立的短句。当前任务进度写在 `memory/working/`，不要写到这里。
服务不会自动往这里写。

左栏目录：标题按字宽（可收缩省略），虚线列吃剩余空隙，随标题和栏宽变长变短。

正文目录与左栏目录都认第N部分、附录、引论；无印张页的部头是章级，不画虚线。

印刷目录里「1 标题 页」在没有 X.Y 父节时是节，不是小节。

目录页缺的部头按原书补进 Markdown，不要靠渲染去猜。

两栏印刷目录若先吐出后一章章头，按节号把条目归回对应章，不要按行序把后一章插到前一章剩余节前面。

教材 sub/sup 导入残留（`<sub>`、`\lt sub\gt` 等）用 `strip_sub_sup` 剥标签留夹心；`refine_page` 复用同一逻辑。

工作区 `toc_extract` 转调 `/app`：先看原文 PDF 目录页，再读 toc.json，然后扫各区间标题写入 `toc_agent.json`；对话里不再另开 Cursor 会话。

印刷目录漏掉的引论、第N部分、附录，由导入后的 `build_toc` 从正文部头页补进 `toc.json` 并写回目录页；两栏归桶只用于第N章，不用部号去拆活动号。

表格脚注写成 `$\lt p class="kb-table-foot"\gt$…$\lt /p\gt$` 时，unwrap 认不到，需剥标签只留来源行。

对扩展开放、对修改封闭：共用代码只认全书形状，不为某一册改解析器。新功能用新工具+事件触发。改 tools/*.py 须先得到用户同意。用户没明文要求改代码、添加工具或加钩子时，默认不改代码。

对话要快：先定位再改；原页图一次一张、不重读；每步一句完整中文让用户看见进度。

印刷目录标题可以是「目录」或 Contents；章可以是第N章或「数字 + 拉丁标题」；节可以是 1.2 或 A–E + 标题 + 页。页码在装饰字体里时按正文板块页减偏移回填。

致同学们一类正文若整页换成错位汉字/字母+1，不要当版式问题改渲染。上海版英语常见原因是方正兰亭 Pro（Adobe-Identity）带了不完整 ToUnicode：已映射的字正常，未映射 CID 被当成 Unicode（同学→⌚、《READING》→3FBEJOH）。中文按 CID+0x30F2 还原（落在 U+4E00–U+4EFF 用 +0x30F3），拉丁按 CID+31；方正大黑 GBK 不要套兰亭公式，只用它自己的 ToUnicode。音标 Times-PhoneticIPA 无 ToUnicode，字码是 ASCII、字形才是 IPA。Mineru 的块类型和框是对的，乱码来自它照抄了 PDF 字层。

导入清洗用 `restore_cid(apply=fix)` 做全书 CID 还原：只改不在《通用规范汉字表》里的错位字，有中文残留才开拉丁还原；规范汉字、圈号、ISBN、页码、数学公式和音标 ASCII 不动。无残留的书 0 hits。

印刷目录没有「目录」或 Contents 标题时，对话手动调用 `mark_toc_pages(book_id, pages)` 指定页：从 Mineru 回收页码标记，只按 `build_toc` 已认的章/节形状写回目录页，不写一书专名，不自动触发。

斜杠音标里 TimesKKPhoneticNewRoman / Times-PhoneticIPA 无 ToUnicode，字码是 ASCII、字形才是 IPA；按书内 Phonetic symbols 表还原（9→ˈ、0→ˌ、I→ɪ、R→ə、C→æ、W→ʊ、N→ŋ、S→ʃ、Z→ʒ、B→ɒ、G→ɡ、V→ʌ、O→ɔ、A→ɑ、F→ɜ、P→θ、Q→ð、:→ː、'→ˈ），用 `restore_ipa`，不要按单词另编。无此类残留的书 0 hits。

`restore_cid` / `restore_ipa` / `mark_toc_pages` 找书径时与 `refine_page` 一样：cwd 下有 `textbooks/` 用它，否则把 cwd 当 `textbooks/`。

拉丁部头若带装饰尾符（如 `Progress?`）先剥尾标点再按「数字 + 拉丁标题 / 裸拉丁组」认章。

`Self-assessment` 无印张页时仍是节；比部头时要去掉连字符。

正文回补的附录写到最后一张印刷目录页，不要默认落到第一张。

拉丁 CID+31 里 `$` `(` `-` 是 C/G/L 的未映射字码，不是公式或列表；已有中文残留时，全大写 ROT31 词也应还原，年份数字除外。

符号区 CID（上标、箭头、几何号、数学符号）在公式落到规范汉字时要还原；、。《》和全角标点不动。

规范汉字里的错位字：源字不在一级字表、目标在一级字表时才按 CID 还原，一级字本身不加第二次偏移。

斜杠音标里只要有 9/0/I 等音标字码就按书内表还原，不因连续小写英文而跳过；HTML 碎片不还原。

知识库科目下「考纲」靠书卡 `category` 挂书，不把考纲正文并进教材页。

书库 POST/PATCH `/v1/library` 现已接受并回传 `category`（textbook / knowledge / syllabus / material / homework）和政史地科目（politics / history / geography）。考纲挂栏用 `category=syllabus`，不把考纲正文并进教材页。

`POST /api/v1/admin/kb/convert/{book_id}` 可排队 MinerU 全书识别，不必在导入页点「开始识别」。单文件超过 200 页会失败，须拆册再识别。

入库、建卡、改卡、对外输卡仍在服务镜像 `/app/app/library.py`。工作区授权卡只能改 `tools/`、钩子、`surfaces/`，改不了这四个函数。

课程标准印刷目录用「一、标题 …… 页」和「（一）标题/页」；`build_toc` 尚未认这种形状时，按印刷目录手写 `toc.json`，不为一书改解析器。

课标部头装饰字体无 ToUnicode，标题落成 `!" #` 这类符号，按印刷目录还原，不套 CID+0x30F2。

正文目录抬升认「一、标题」为章、「（一）标题/页」为节；页码可以是行末空格数字或斜杠页，不把抬升 HTML 写回书页。

课标正文标题层级：一、为一级，（一）为二级，主题/【】/类课程为三级，1．为四级，（1）为五级；①不升为标题、不进左栏。左栏按全文标题生成，不限于印刷目录两级。

中文正文段首缩进两字用 page-body 的 `p { text-indent: 2em }` 画，不在 Markdown 里塞全角空格；列表、表注、题解不加段首缩。

课标「（1）（2）（3）」短标题 Mineru 常只把第一条标成 title，后续落成段落；同组短标题要补升为五级并写进左栏，习题问句和算式不升。

课标空占位 `![表格](images/)` 按该书 PDF 版面文字回补，不另编；词汇双栏按两列表，学业质量续表按「水平／质量描述」。

沪教版数学教材标题不全时按正文补全，不改解析器：节号与标题拆行要拼回「X.Y 标题」，章头「第」与章名拆开要拼回「第N章 标题」，小节丢掉序号的按同组 1、2、3 补回；装饰字 员→圆、犃/犅→A/B；正文句子和「达到最小值」这类碎片不进左栏。

沪教版数学正文标题按章/节/小节写成二到四级；例题、练习、A组/B组保持正文，page-body 不再把「例1」「练习1.1」抬成标题。

国家自2020年起不再制定高考考试大纲；实施新课程后命题依据课程标准与高校人才选拔要求。上海现行可对标的是各科课程标准、市教委年度合格考/等级考命题要求和《中国高考评价体系》，不是每年一本「高考大纲」。

上海招考热线「大纲教材」栏是高等教育自学考试，不是高考。上海卷《考试手册》至少编到2022年，之后公开渠道主要是课标加年度命题要求。

沪教英语必修、选择性必修各册导入后须跑 `restore_cid`、`restore_ipa`；印刷目录页以该书版心为准（必修常见 6–7，选择性必修第1册是 5–6、第7页起正文），MinerU 抽成图时用 `mark_toc_pages` 指定页，缺条按同套已还原册和正文单元名补，不为一书改解析器。版权页 `hram` 是 ISBN 的 ROT31。

沪教英语印刷目录是双栏活动预览：单元号（1 The media）不能省；A 栏下要列 Reading / Mini-project / Focus on language，C/D/E 下列 Listening、Speaking、Writing 活动名和 Video。只留 A–E 会丢印刷目录。页码在装饰字体里时用 PDF 字层标题，印张页按已有偏移回填。

沪教英语目录三级是单元 / A–E / Reading·Mini-project；画面纯文本解析只把 1.1.1 当成三级，活动行会和 A–E 同级。目录页写 `kb-page-toc` 的 lv0/lv1/lv2，不为一书改解析器。

沪教英语左栏和正文目录标现在的 PDF 页，不标印刷页脚；正文里 Grammar reference (p.) 和 on page 也按现在的页。Appendices 与「附录」不并存。Vocabulary / Proper nouns 的 Unit 1–4 和 Grammar reference 编号条进左栏与目录页。

知识库显示名「第N册」用阿拉伯数字，不用汉字；改显示名用 `propose_import_meta`。PDF 文件名和书页正文仍照原书汉字册号。
