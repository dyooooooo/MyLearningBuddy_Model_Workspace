左栏目录：标题按字宽（可收缩省略），虚线列吃剩余空隙，随标题和栏宽变长变短。

正文目录与左栏目录都认第N部分、附录、引论；无印张页的部头是章级，不画虚线。

印刷目录里「1 标题 页」在没有 X.Y 父节时是节，不是小节。

两栏印刷目录若先吐出后一章章头，按节号把条目归回对应章，不要按行序把后一章插到前一章剩余节前面。

教材 sub/sup 导入残留（`<sub>`、`\lt sub\gt` 等）用 `strip_sub_sup` 剥标签留夹心；`refine_page` 复用同一逻辑。

工作区 `toc_extract` 转调 `/app`：先看原文 PDF 目录页，再读 toc.json，然后扫各区间标题写入 `toc_agent.json`；对话里不再另开 Cursor 会话。

印刷目录漏掉的引论、第N部分、附录，由导入后的 `build_toc` 从正文部头页补进 `toc.json` 并写回目录页；两栏归桶只用于第N章，不用部号去拆活动号。

表格脚注写成 `$\lt p class="kb-table-foot"\gt$…$\lt /p\gt$` 时，unwrap 认不到，需剥标签只留来源行。

对扩展开放、对修改封闭：共用代码只认全书形状，不为某一册改解析器。新功能用新工具+事件触发。改 tools/*.py 须先得到用户同意。用户没明文要求改代码、添加工具或加钩子时，默认不改代码。

对话要快：先定位再改；原页图一次一张、不重读；每步一句完整中文让用户看见进度。

印刷目录标题可以是「目录」或 Contents；章可以是第N章或「数字 + 拉丁标题」；节可以是 1.2 或 A–E + 标题 + 页。页码在装饰字体里时按正文板块页减偏移回填。

致同学们一类正文若整页换成错位汉字/字母+1，不要当版式问题改渲染。上海版英语常见原因是方正兰亭 Pro（Adobe-Identity）带了不完整 ToUnicode：已映射的字正常，未映射 CID 被当成 Unicode（同学→⌚、《READING》→3FBEJOH）。中文按 CID+0x30F2 还原（落在 U+4E00–U+4EFF 用 +0x30F3），拉丁按 CID+31；方正大黑 GBK 不要套兰亭公式，只用它自己的 ToUnicode。音标 Times-PhoneticIPA 无 ToUnicode，字码是 ASCII、字形才是 IPA。Mineru 的块类型和框是对的，乱码来自它照抄了 PDF 字层。

导入清洗用 `restore_cid(apply=fix)` 做全书 CID 还原：只改不在《通用规范汉字表》里的错位字，有中文残留才开拉丁还原；规范汉字、圈号、ISBN、页码、数学公式和音标 ASCII 不动。无残留的书 0 hits。

印刷目录没有「目录」或 Contents 标题时，对话手动调用 `mark_toc_pages(book_id, pages)` 指定页：从 Mineru 回收页码标记，只按 `build_toc` 已认的章/节形状写回目录页，不写一书专名，不自动触发。

斜杠音标里 TimesKKPhoneticNewRoman / Times-PhoneticIPA 无 ToUnicode，字码是 ASCII、字形才是 IPA；按书内 Phonetic symbols 表还原（9→ˈ、0→ˌ、I→ɪ、R→ə、C→æ、W→ʊ、N→ŋ、S→ʃ、Z→ʒ、B→ɒ、G→ɡ、V→ʌ、O→ɔ、A→ɑ、F→ɜ、P→θ、Q→ð、:→ː、'→ˈ），用 `restore_ipa`，不要按单词另编。无此类残留的书 0 hits。

`restore_cid` / `restore_ipa` / `mark_toc_pages` 找书径时与 `refine_page` 一样：cwd 下有 `textbooks/` 用它，否则把 cwd 当 `textbooks/`。

拉丁部头若带装饰尾符（如 `Progress?`）先剥尾标点再按「数字 + 拉丁标题 / 裸拉丁组」认章。

`Self-assessment` 无印张页时仍是节；比部头时要去掉连字符。

正文回补的附录写到最后一张印刷目录页，不要默认落到第一张。

拉丁 CID+31 里 `$` `(` `-` 是 C/G/L 的未映射字码，不是公式或列表；已有中文残留时，全大写 ROT31 词也应还原，年份数字除外。

符号区 CID（上标、箭头、几何号、数学符号）在公式落到规范汉字时要还原；、。《》和全角标点不动。

规范汉字里的错位字：源字不在一级字表、目标在一级字表时才按 CID 还原，一级字本身不加第二次偏移。

斜杠音标里只要有 9/0/I 等音标字码就按书内表还原，不因连续小写英文而跳过；HTML 碎片不还原。

知识库科目下「考纲」靠书卡 `category` 挂书，不把考纲正文并进教材页。

书库 POST/PATCH `/v1/library` 现已接受并回传 `category`（textbook / knowledge / syllabus / material / homework）和政史地科目（politics / history / geography）。考纲挂栏用 `category=syllabus`，不把考纲正文并进教材页。

`POST /api/v1/admin/kb/convert/{book_id}` 可排队 MinerU 全书识别，不必在导入页点「开始识别」。单文件超过 200 页会失败，须拆册再识别。

入库、建卡、改卡、对外输卡仍在服务镜像 `/app/app/library.py`。工作区授权卡只能改 `tools/`、钩子、`surfaces/`，改不了这四个函数。

课程标准印刷目录用「一、标题 …… 页」和「（一）标题/页」；`build_toc` 尚未认这种形状时，按印刷目录手写 `toc.json`，不为一书改解析器。

课标部头装饰字体无 ToUnicode，标题落成 `!" #` 这类符号，按印刷目录还原，不套 CID+0x30F2。

正文目录抬升认「一、标题」为章、「（一）标题/页」为节；页码可以是行末空格数字或斜杠页，不把抬升 HTML 写回书页。

课标正文标题层级：一、为一级，（一）为二级，主题/【】/类课程为三级，1．为四级，（1）为五级；①不升为标题、不进左栏。左栏按全文标题生成，不限于印刷目录两级。

中文正文段首缩进两字用 page-body 的 `p { text-indent: 2em }` 画，不在 Markdown 里塞全角空格；列表、表注、题解不加段首缩。

课标「（1）（2）（3）」短标题 Mineru 常只把第一条标成 title，后续落成段落；同组短标题要补升为五级并写进左栏，习题问句和算式不升。

课标空占位 `![表格](images/)` 按该书 PDF 版面文字回补，不另编；词汇双栏按两列表，学业质量续表按「水平／质量描述」。

沪教版数学教材标题不全时按正文补全，不改解析器：节号与标题拆行要拼回「X.Y 标题」，章头「第」与章名拆开要拼回「第N章 标题」，小节丢掉序号的按同组 1、2、3 补回；装饰字 员→圆、犃/犅→A/B；正文句子和「达到最小值」这类碎片不进左栏。

沪教版数学正文标题按章/节/小节写成二到四级；例题、练习、A组/B组保持正文，page-body 不再把「例1」「练习1.1」抬成标题。

国家自2020年起不再制定高考考试大纲；实施新课程后命题依据课程标准与高校人才选拔要求。上海现行可对标的是各科课程标准、市教委年度合格考/等级考命题要求和《中国高考评价体系》，不是每年一本「高考大纲」。

上海招考热线「大纲教材」栏是高等教育自学考试，不是高考。上海卷《考试手册》至少编到2022年，之后公开渠道主要是课标加年度命题要求。

沪教英语必修、选择性必修各册导入后须跑 `restore_cid`、`restore_ipa`；印刷目录页以该书版心为准（必修常见 6–7，选择性必修第1册是 5–6、第7页起正文，第2、3册同样是 5–6、第8页起正文），MinerU 抽成图时用 `mark_toc_pages` 指定页，缺条按同套已还原册和正文单元名补，不为一书改解析器。版权页 `hram` 是 ISBN 的 ROT31。选必第3册第一、三单元后有 Exploring literature；印张页加 3 即现在的 PDF 页。

沪教英语印刷目录是双栏活动预览：单元号（1 The media）不能省；A 栏下要列 Reading / Mini-project / Focus on language，C/D/E 下列 Listening、Speaking、Writing 活动名和 Video。只留 A–E 会丢印刷目录。页码在装饰字体里时用 PDF 字层标题，印张页按已有偏移回填。

沪教英语目录三级是单元 / A–E / Reading·Mini-project；画面纯文本解析只把 1.1.1 当成三级，活动行会和 A–E 同级。目录页写 `kb-page-toc` 的 lv0/lv1/lv2，不为一书改解析器。

沪教英语左栏和正文目录标现在的 PDF 页，不标印刷页脚；正文里 Grammar reference (p.) 和 on page 也按现在的页。Appendices 与「附录」不并存。Vocabulary / Proper nouns 的 Unit 1–4 和 Grammar reference 编号条进左栏与目录页。

知识库显示名「第N册」用阿拉伯数字，不用汉字；改显示名用 `propose_import_meta`。PDF 文件名和书页正文仍照原书汉字册号。

英语课文里带 `^{n}` 脚注或填空号时，`improve_render(apply=safe)` 会把整段包进 `$`，再被撇号提前闭合；只给上标包 `$^{n}$`，不要整句包美元符。目录页上的 `kb-page-toc` 不要再 unwrap。

课标附录N要从表题抬成节并写进左栏；词汇表字母A–Z和「主要国家名称」按该字母首现页进左栏。教学案例里的题解、学生作业、活动步骤不进左栏。

人教版语文必修上/下册印刷目录都跨第4–6页；只认第4页会截断后半并混入右栏页码。第5–6页已是 `kb-page-toc` 时不要再 `mark_toc_pages` 或 unwrap，否则会收成一行或只剩 Contents。

人教语文选择性必修中册、下册印刷目录都跨第4–5页；只认第4页会截掉第四单元和古诗词诵读。印张页加5即现在的PDF页。「单元研习任务」是节（lv1），各单元按自己的印张写 `pdf_page`，不要全跳到目录页上的5。手写印张页后不要再调 `fill_unit_toc` 覆盖。

正文目录行末必须写印张页，读页用 `print_to_pdf` 映射成 `data-goto-page`；写成现在的 PDF 页会对不上映射，点击无跳转或跳错。`fill_unit_toc` 的 `_official_line` 会按 `pdf_page` 写回行末，印张与 PDF 不一致的书不要再调它覆盖目录页。

`fill_unit_toc` 解析时会把行首 `*` 当列表符剥掉；自学篇星号写进 `toc.json` 后再 reused 重写三层，不要改解析器。

多个「单元学习任务」按标题正文首现会全跳到第一处；各自按印张页加偏移写 `pdf_page`。

人教版语文必修「第N单元」`build_toc` 不认；按印刷目录和正文单元页手写 `toc.json` 与目录页 `kb-page-toc` 的 lv0/lv1/lv2，不改解析器。印张页加 7 即现在的 PDF 页；左栏和正文目录标现在的 PDF 页。自学篇目前加 *。

语文教材课序号「1」「2」「3」是节（lv1），后面不拼接作品名；同课篇名（含首篇和 *自学）都是该序号下的小节（lv2），彼此并列。

语文课文里 `Days^{④}`、`Anthology^{②}` 这类拉丁词加脚注，`improve_render(apply=safe)` 会把整词包进 `$`；只改成 `Days$^{④}$`，不要整句包美元符。

语文圈号页注用 `restore_footnotes`：只认 ①〔 / 选自 / 节选，正文上标写成 `$^{n}$`，注释块上方加 `---`；活动题行首 ① 不收进页脚，封面和目录页不改。

页注前的 `---` 上下必须空行，否则 Markdown 会把上一段收成二级标题，整段变黑体，横杠也看不见。注释只留在有对应上标的那一页，不要把邻页的〔词〕释义挂过来。

原文一段被印张打断、MD 并进上一页时：后页从①起的注释也放到这一页，编号从本页第一段最大号接着编，正文上标一起改。不要拆回两页，也不要两个①并存。

语文课文末级目录是「篇名 / 作者」时，正文写成 `## 篇名` 加下一行作者；标题加粗、与其他课文同字号。不要写书页 HTML，也不要为居中改 page-body。用 `center_article_heads`，不要手写一书。

书页三层：`pages/` 只写官方 Markdown，`mid/` 只写 `::: kb-*` 围栏，点线/居中/缩进只在读页时由 `prepare` + `theme.css` 画。禁止把 `<nav>` / `<ol class="kb-page-toc">` 写进书页。人教语文「第N单元」目录调 `fill_unit_toc`：`toc.json` 已按单元/课号/篇名写好时只重写三层文件，不再按正文首现回填页码。

语文教材「学习提示」一类栏目：中间文件用 `::: kb-section-icon` 把小图标和标题收成一组；读页时画成同一行、靠左置顶、赤褐色、右侧点线。不要把图标单独 `kb-center`，也不要把点线写进书页。源页标题上下各空一行；闭栏后必须再空一行，否则正文粘在 `:::` 上不成段。栏下首段缩进由读页 CSS，不要写全角空格。`tag_section_icons` 必须走 `library.write_mid`，直接改 `mid/*.md` 印章会过期，版式闸门会按源页重建并把图标收成 `kb-center`。

其他科目若小圆标紧贴栏目标题左侧（如物理问号在「为何要构建物理模型？」前），中间文件同样用 `::: kb-section-icon`，经 `library.write_mid`，不要把图标单独 `kb-center`。`tag_section_icons` 仍只认语文栏名，一书一页经闸门收。

插图 alt 不要写半角 `[清]`：`![琵琶行 [清］ 改琦 作](url)` 里未配对的 `[` 会让 CommonMark 把后面的 `]` 当成内层闭合，整张图认不成。alt 写成 `琵琶行［清］改琦作`，图下说明仍用原书 `*琵琶行 [清] 改琦 作*`。

中间文件不要把 `::: kb-center` 嵌进 `::: kb-list-item`：闭栏吃到第一道 `:::`，内层围栏会被当正文转义，页面上露出 `:::`。导读正文不要整段 `kb-center`；源页也不要写围栏。

跨页学生填空表按印张拆开写，不要把后页行并进前页，也不要把右栏溢出字硬接到上一行。空占位 `![表格](images/)` 用该书 MinerU 该页表块回补。学习任务、任务N 这类栏目标题不要套 `kb-title`，否则会居中。

一词多义「例1：绝」「例2：信」这类例题：各例的①–⑥留在该例标题下，不要抽空甩到页底混成一组编号；例标不要升成 `##`，也不要套 `kb-title`。

人教语文「古诗词诵读」：行长不一、左缘齐的诗（如《无衣》）整首一个 `kb-verse`（整块居中、行左齐）；行长相近、各行居中的用 `kb-verse-center`。导读散文不包。栏目标题「古诗词诵读」不是停栏；漏标时走 `write_mid` 补围栏，不要手写书页 HTML。

人教语文古文是通栏左齐、段首缩进的散文，不要套 `kb-verse` / `kb-verse-center`：前者 `fit-content` 加 `margin: auto` 会把短句整块居中，后者是诗行居中；篇名/作者仍用 `kb-title` / `kb-author`。

语文戏剧对白用 `::: kb-drama`：角色加粗左齐、台词悬挂折行，（舞台说明）略淡；开场说明用 `::: kb-stage` 左右缩进。不要收成表格或普通缩进正文。杂剧「（云/唱）」和「【曲牌】」走同一围栏。用 `tag_drama` 经 `write_mid`，不要手写书页 HTML。

话剧角色名与台词粘连时，源页角色名后补空格，读页才会拆成人物/台词两栏；改源后围栏被冲掉再调 `tag_drama`，不要手写 `mid/`。

印张末页只剩一句对白时，`tag_drama` 不收单句围栏；经 `library.write_mid` 补 `kb-drama`，不要直接改 `mid/*.md`。

戏剧对白不要套 `kb-verse`：版式任务常把短对白收成诗行，人物栏就拆不开；整页对白收成一个 `kb-drama`，经 `library.write_mid`。MinerU 把对白两栏收成表、后页只剩空 `![表格](images/)` 时，用 layout 预处理表 HTML 按印张回补，后页行不要并进前页。

跨页话剧页首若被版式收成 `kb-verse`，`tag_drama` 见页上已有 `kb-drama` 会整页跳过；须经 `library.write_mid` 把页首说明收成 `kb-stage`、对白并成一个 `kb-drama`，不要留诗行围栏。印张切断、无角色名的续行留在下一页 `kb-drama` 里，不要另包诗行。

演说类「篇名 + 年月日在某地 + 作者」中间文件用 `kb-title` / `kb-subtitle` / `kb-author`，读页收成 `kb-work-head` 居中。不要用 `kb-section`（左齐）或 `kb-date`（右齐，那是诗题署年）。经 `library.write_mid`，不要直接改 `mid/*.md`。`center_article_heads` 的日期只认括号年，夹在中间的「1856年4月14日在伦敦」会被误升成 `##`，这类页不要跑全书 fix。

推理链里的结论短句（如「只有自己去拿」）不是栏目标题：不要升 `##`、不要套 `kb-section`。MinerU 常把短行标成 title。

MinerU 右栏圈号页注常标成 `ref_text`，回补时要和 `page_footnote` 一起收；`②6` 或半角 `[]` 包词头、以及「① 本文根据」这类不带〔〕的题注，也要对回正文上标。

正文上标已并进上一页、注释还停在下一页时，按词头搬到有上标的那一页并接着编号。后页只剩已并走的条就清空，不要留第二份。不要再对已修好的书盲跑 `continue_fn_series`：它会把㉑收成 `$^{②}$`，再加成㊷–㊺。并页后若正文⑲后跳到㉑、页注⑳后跳到㉕，是它把误读的㉑当成最大号；按栏序补㉑起并把后续号下移，不要把⑳改成㉑。

已有页注的语文书若正文仍是裸 `^{n}` 或篇名后直接跟圈号，只包成 `$^{n}$`，不要再跑 `restore_footnotes`，以免按 MinerU 重写已经并页的注释。读页不会把裸 `^{n}` 收成上标。

语文页注词头用〔〕，题注「选自/节选」不套〔〕；正文与注释之间必须有上下空行的 `---`，否则读页把注释当正文。21 以上写成 `②1` 的拼号要收成 ㉑。右栏圈号常被认成 ⑲/⑳ 导致缺条，按栏序和正文上标补，不要按短词头对号。栏切开的题注半句要接回同一条，不要留在诗句中间。

`improve_render(apply=safe)` 后再 `unwrap` 即可；不要来回再 safe，否则会把 `kb-table--fit`、`::: kb-center` 写回源页。源页里的裸 `kb-center` / `::: kb-` 要剥掉，居中只留 mid。

图题和图片 alt 里的裸 `\mathrm` / `\frac` 扫描会记成 bare_latex；不要为这两处再跑全书 safe。

沪科物理导入后用户指出的问题，共性是 MinerU 按识别框拆图、按行粘栏、公式定界符丢失；按原书整框或整栏收回，只在出错处补 `$` / 图题，不要再跑全书 safe，源页不写围栏。

物理教材示意图图题写在图下斜体行，alt 与图题同文；MinerU 的 image_caption 未落下时按该书回补。源页不要写 `::: kb-center`，居中只留 mid。

物理组合图（主图 + 局部放大/放大镜）MinerU 常拆成多张 chart/image 且框重叠；按原书收成一张，不要留残片，也不要把图题再裁成单独一张图。页底双手持传感器一类图若被拆成两块、左块还被甩到页首，按原书收成一张放到对应自主活动之后，不要留页首无题残片。

（a）（b）并排的原理示意图，不要把「图 N-M …」整题粘在（b）上；整框收成一张，图下只留一行图题，（a）（b）和发射器等标识留在图里。

物理公式里的撇号点写成 `$A^{\prime}$` / `$B^{\prime\prime}$`，不要写成 `$A'$`，以免撇号提前闭合美元符。MinerU 常把 `和 $B^{\prime\prime}$` 落成缺开头 `$` 的 `和B ^ { \prime \prime }$`，再多出一个空 `$$`；按原文补配对，数字和单位不要留 `2 . 0`、`m / s` 这种空格。实验结论里的 `v = \_ m/s` 是填空，写成 `$v = $ ____ $\mathrm{m/s}$`，不要包成 `$v = _ m/s$` 变成下标。

`improve_render` 的 BARE_SUB 只认无空格 `t_{`，认不到 MinerU 的 `t _ { 1 }`；物理正文这类裸下标要包成 `$t _ { 1 }$`，不要为此再跑全书 safe。实验记录「弹簧原长 x₀ = m」也是填空，写成 `$x _ { 0 } =$ ____ $\mathrm{m}$`。

物理正文里表示时间区间的裸 `0~t` 会被 Markdown 收成删除线（两处波浪号配对）；要写成 `$0 \sim t$`，与书内 `$0 { \sim } t _ { 1 }$` 一类写法一致。图题里的 `0~100` 同样写成 `$0 \sim 100$`。

物理表题 caption 里 MinerU 已包的单位公式，导入后常丢掉美元符，只在该表题补回 `$[a/(\mathrm{m}\cdot\mathrm{s}^{-2})]$` 一类写法，不要为此再跑全书 safe。表内数量级与同列 `10^{n}` 一律包进美元符。

物理附录索引两栏「词条 / 印张页」被 MinerU 粘成一段或按行左右交错时，按栏序拆成一行一条，标题「索引」置顶；中间文件留 `kb-page-toc`，不要为此改解析器。

并页或按原书重裁后的新图哈希要写回 `mineru/blocks.json`（框用原书印张尺寸），否则 `fig_size` 对不上，读页会按满栏放大。不要把 `width` 写进 `pages/` 或 `mid/`。

物理小结「知识结构图」是带顶框的流程图，不要收成 HTML 表；按原书整框截图，源页只写插图，居中只留 mid。

重裁后的新图哈希除了写 `mineru/blocks.json` 和 `textbooks/.../images/`，还要落到该书 mineru 资源里；只改 Markdown 指向未入库的哈希，读页会裂图。

`improve_render` unwrap 后源页常留下会显示出来的 `kb-center` / `:::` 残片，要从 `pages/` 剥掉；居中只留 mid。剥残片时不要把中间文件里任意 `:::` 都当孤儿删掉，否则会拆开 `kb-page-toc` / `kb-list-item`。源页和 mid 表上的 `class="kb-table--fit"` 要一起去掉，只改源页会被闸门写回。

化学正文里 MinerU 常把「和 $\mathrm{X}$」落成缺开头 `$` 的 `和\mathrm { X }$$`；按原文补配对，不要为此再跑全书 safe。表注 `kb-table-foot` 剥成纯文本后，不要整文件改 mid 围栏，否则闸门会把 `::: kb-table-wrap` 写回源页。

已闭合的 `证明有$\mathrm{X}$` 不要用「证明有$\mathrm{X}」前缀去补美元符，否则行末会多出一个 `$`。unwrap 把表收成 `$\lt table class=$"kb-table--fit"$` 时，按表头还原成无 class 的 HTML 表；先改 mid 再改源页，以免闸门把 class 写回。

化学教材「学习聚焦」条目用对号 `√`，「知识回放」用 `●`；MinerU 裁出的对号残图从源页剥掉，栏可放页底。栏目说明页不改。化学专属版式进 `tag_chemistry`，不要另起特指某一栏的工具名；任务只触发化学教材。
